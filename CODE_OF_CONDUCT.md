# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We pledge to make participation in this project a harassment-free experience for everyone. Be respectful,
assume good intent, and focus on what is best for the community.

Report unacceptable behaviour to the project team at **support@sourcefuse.com**. All reports are
reviewed and investigated promptly and fairly, and the reporter's privacy is respected.
